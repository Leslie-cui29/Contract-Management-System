## 项目结构

```
src/
├── components/         # 公共组件
│   └── MainLayout.tsx # 主布局组件
├── context/           # 上下文
│   └── AuthContext.tsx
├── pages/             # 页面组件
│   ├── Login.tsx
│   ├── Dashboard.tsx
│   ├── ContractUpload.tsx
│   ├── AIAssistant.tsx
│   └── ContractSearch.tsx
├── services/          # API 服务
│   └── api.ts
├── types/             # TypeScript 类型定义
│   └── index.ts
├── App.tsx            # 主应用组件
├── main.tsx           # 入口文件
└── index.css          # 全局样式
```

## 安装和运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 技术栈

- **React 19** - UI 框架
- **TypeScript** - 类型安全
- **React Router 7** - 路由管理
- **Tailwind CSS 4** - 样式框架
- **Axios** - HTTP 客户端
- **Heroicons** - 图标库
- **Vite** - 构建工具

## 注意事项

- 确保后端 API 已经启动并运行在 `http://localhost:8000`
- 所有的 API 请求都会通过 Vite 代理转发到后端
- Token 存储在 localStorage 中，注意安全性
- 生产环境需要配置正确的 API 地址
